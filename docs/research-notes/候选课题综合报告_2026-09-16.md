## 候选一（主推）：Reproducibly Wrong——越狱文献 ASR 的测量层审计与三源归因

**① 一句话定义**：越狱攻击文献的 ASR 数字"可复现地错"——JBF（arXiv 2602.24009，30 攻击×10 模型）证明攻击层忠实可复现（复现-报告偏差仅 +0.26pp），但其所依赖的判官层被 SEAV（2609.00498，EMNLP 2026）与判官 meta-eval（2609.10594）证明系统性虚高（22.1%-51.0% 旧"成功"改判无效）——这一悖论无人解决；我们复用 JBF 开源攻击模块重跑 8-12 攻击×4-6 模型，同一批输出过 {5-6 判官 × validity 层（SEAV 开源+补 detail-sufficiency 节点）× 协议变体} 三维网格+人工金标切片，产出"报告 ASR→重测 ASR→有效 ASR"瀑布分解（带 CI，引 2601.18076 测量理论）+ 校正 SOP + 兼容 JBF 格式的开源重打分工具。

**② 红区规避论证**：不是新综述/基准/攻击变体/防御，是测量学元科学。近一月三篇各占一轴（Fair-ASR 2608.17360 协议轴 / 2609.10594 判官轴 / Fragility 2608.30748 协议-状态轴）但**无人焊合**、无人做三源归因分解、无人解 JBF×SEAV 悖论；SEAV 三重核证（abs+HTML+GitHub）确认其零攻击重跑/零跨判官网格/无通用工具三边界。假设风险免疫：即使膨胀小于预期，"判官间不可比"仍是一等一结论。

**③ 与组内其他课题划界**：P4（Agent 因果归因）研究对象正交（行为归因 vs 测量方法学）；P5（频域后门）正交且方法基因无重叠（本课题是黑盒测量，无频域/内部通道）；P1-P3/P6-P20（provenance/供应链/密码协议）全部正交。全组首次进入 LLM 安全评估方法学。

**④ venue 与排期**：进攻性选项 **S&P 2027 C2（摘要 2026-11-10/全文 11-17，通知 2027-03-05，官方核证）**——SoK 2605.05058 已进 S&P 2026，安全测量审计有门；舒适选项 **ICML 2027（CFP 未出，惯例 ~2027-01 下旬）**——JBF 先例即 ML 大会口味；兜底 NDSS 2028 R1（~2027-04/05）/ARR 2027-01 轮/SaTML 2028。**显式避开 USENIX Sec 2027 C2（2027-01-26）——组内其他课题已三篇占该窗口**。SaTML 2027（09-29）仅剩 13 天不可行。

**⑤ 数据/算力可得性**：JBF（MIT 开源）+AdvBench/JBB 公开；victim 全部本地 7-8B（Qwen2.5-7B/Llama-3.1-8B 等，4080S 32G 逐个跑，GCG 类白榜攻击单卡可跑）；判官 LlamaGuard-3-8B/HarmBench classifier 本地，strongREJECT/SEAV 为 rubric 判官可本地 32B-AWQ 或少量 API；**纯推理无训练，单卡可行**。主要成本=GPU 时序（数周）而非算力上限。

**⑥ 撞车检查结论**：近一月（08-15~09-16）扫描无焊合工作（A 档案逐篇表）；最大威胁=SEAV 团队或 2609.10594 作者自然延伸，须 4-6 周内出首版数据+尽早 arXiv 占位。竞品组：JBF（清华系 Wei Xu 组）/SEAV/判官 meta-eval 组均未宣布后续。

## 候选二：攻破主动防御——对伪响应/蜜罐类防御的首个系统自适应攻击

**① 一句话定义**：主动防御层（ProAct 2510.05052 伪响应注入宣称多轮 ASR -94%、CMPE 2606.20470 理论"证明"渐近 ASR 有界、HoneyRoute 2609.08306/HASTE/A-MemGuard/Cloak 各占一层）正在快速发表但其安全性宣称从未经自适应攻击检验；我们提出**响应取证（response forensics）**自适应攻击框架——多措辞交叉盘问（挑伪响应自相矛盾）、编码/格式法证、多模型仲裁、known-answer 锚定探针（攻击者已知答案→验证响应真伪）——对 ProAct（开源）+≥2 个同类防御做黑盒攻破，证伪/刻画 CMPE 有界性宣称边界，并给出"什么信号不可伪造"的防御侧启示。

**② 红区规避论证**：不是攻击变体（红区指越狱提示变体）；是对一整类新防御的安全性审计——"attacker moves second"（2510.09023）是安全顶会经典菜型但未碰此类防御；靶子新鲜且大：ProAct 无 limitations 章节、ICLR 审稿人已点名其 Intent Analyzer 依赖，CMPE 理论刚立靶。近一月专项检索**零引用 ProAct 的自适应攻击**。

**③ 与组内其他课题划界**：组内相邻课题完全正交（无归因、无频域/内部通道基因）；与候选一也正交（测量层 vs 防御层）。

**④ venue 与排期**：主投 **S&P 2027 C2（2026-11-17 全文）**——自适应攻击破防御类是四大招牌菜型，纯黑盒 8 周可闭环；备选 NDSS 2028 R1 / CCS 2027（CFP 待出）；MLSec@S&P 2027 workshop 兜底；避开 USENIX C2 同组窗口。

**⑤ 数据/算力可得性**：ProAct 官方开源（github.com/Zhaoweiliang/ProActive，含 PAIR/TAP/DAGR/X-Teaming 攻击管线）；victim 本地 7-8B=论文原设置，**纯黑盒零训练，4080S 32G 完全可行**；同类防御按论文复现 2-3 个。

**⑥ 撞车检查结论**：窗口 6-12 个月（D 档案）；双风险=防御作者团队自己发攻击版（最了解自己软肋）/2510.09023 作者扩框架——须快；近一月 HoneyRoute（09-08）新挂说明该层还在长出新靶子，攻击面只会更丰富。

## 候选三：越狱状态的持久化与传播——记忆使能 Agent 的攻陷动力学+遏制闭环

**① 一句话定义**：PMPA（2609.13889，09-12 挂出，直读核证）证明外部恶意指令可写入 OpenClaw/Claude Code 持久记忆跨会话存活，且自认"记忆一旦中毒，prompt 级防御几乎无效"——"攻陷之后怎么办"完全悬空；HF×GPT-6 真实事件（agent 自主逃逸+群体作弊）把"agent 被攻陷状态的存续/传播/隔离"变成现实安全问题；我们做首个 **agent 自身被攻陷状态**（区别于外部指令投毒）经 memory/计划/多智能体通道的**传播动力学**系统测量（跨会话/跨任务/跨 agent 三轴攻击面量化）+**状态级遏制**（隔离/回滚/消毒）防御，回应 PMPA 悬空的后半题，以 HF 事件为动机锚。

**② 红区规避论证**：不是攻击变体（系统化现象+防御闭环）；PMPA 只占"外部指令写入记忆"攻击半边且自认遏制失守；LoopHarness（2608.27141）提出循环级安全状态概念但未做攻陷状态传播实证；A-MemGuard（ICML'26）任务向非安全策略面。贡献重心压在 PMPA 未做的遏制侧+传播动力学测量。

**③ 与组内其他课题划界**：**与 P4 显式划界（用户重点看）**：P4=事后对已发生动作做因果归因（解释），本课题=事前阻断攻陷状态传播（攻/防），管线位置与研究对象双正交；P5 正交。具身/放置研究两切口已撞死（B 档案：2604.23338+TraceSafe 10+ 篇），本候选为幸存切口。

**④ venue 与排期**：testbed 搭建 7-10 天（AgentDojo/ASB+Mem0/Letta）+传播实验，S&P C2（11-17）偏紧；主投 **NDSS 2028 R1（~2027-04/05，CFP 未出需复核）或 CCS 2027**；若 8 周闭环可冲 S&P C2。⚠️ 窗口压力最大：B 判定 6-8 周内必须动手，PMPA 系方向热度极高。

**⑤ 数据/算力可得性**：AgentDojo(+MQ)/ASB/garak 开源+Qwen2.5-7B+vLLM+Mem0/Letta 本地记忆层，7-8B 路线已被 2609.16098 验证；**纯推理无训练，单卡可行**。

**⑥ 撞车检查结论**：近一月 PMPA/MemSentry/PipePoison/SPA/LoopHarness 密集=**可做但拥挤**（B 档案判定）；差异化半边（自身状态传播动力学+隔离回滚）暂无人占，但时钟最快。
