## 二、新发现必引文献（4 篇，全部需在 Related Work 划界）

1. **"A Coin Flip for Safety: LLM Judges Fail to Reliably Measure Adversarial Robustness"（arXiv 2603.06594，Schwinn/Ladenburger/Beyer/Mofakhami/Gidel/Günnemann，TUM；v1 02-04/v2 03-15；ICML 2026；已引 26）** ✅abs 直读。判官轴**最强近邻**：6642 条人标审计，红队条件下判官接近随机；提出 ReliableBench + JudgeStressTest；关键句"many attacks inflate reported success rates by exploiting judge weaknesses rather than actually producing harmful content"——与我们的 base64 幻觉假阳机制互证。**划界**：固定响应集审计+判官压力测试（单轴）vs 我们攻击重跑×12 判官网格×validity×瀑布×锚点对齐（三源焊合）；其"攻击利用判官弱点"论点恰为我们 base64/AIM 结构性零分现象提供独立佐证——引为盟友+划界。代码 SchwinnL/LLMJudgeReliability。
2. **"Attack Success Rate Is Not a Number: On Measurement Validity in Agentic AI Security Evaluation"（arXiv 2609.25173，Pathade/Pawar/Patil，**09-21 提交**，7 页）** ✅abs 直读。agentic 安全域 meta 分析（259 篇，58-65% 无重复运行/方差、判官协议 64 篇中仅 29.7% 报告与人标一致性）+ 功效分析（100 例基准最小可检 ASR 差 18.2pp；5pp 真差单次评估误序率 ~21%）+ **十项报告清单**。结论句"cross-paper ASR comparison is currently unsupported"。**定位=盟友旁证（跨域）+部分重叠**：其不做重跑/判官对比/金标/瀑布；其十项清单与 ASR-Card 有概念重叠——**我们差异化=实证校准链（per-judge P/R/FPR+RG 校正因子）+重打分工具+锚点判官对齐，不是纯报告条目**。须尽早引用防"清单首创"误判。
3. **"Single-Configuration Attack Success Rate Is Not Enough"（arXiv 2605.09070，Maple/Kumar/Tapwal，05-09）** ✅作者页 API 直读。提出 VSM（Variant Sensitivity Measure）与 Union Coverage，主张攻击参数配置分布化报告。**配置分布轴**划界（无判官/无 validity/无文献重跑对齐）。
4. **"Faithful or Fabricated? A Causal Framework for Rationalization Bias in LLM Judges"（arXiv 2605.23970，同组，05-13）** 🔍记录待引：判官合理化偏差因果框架。
